# 🇮🇳 FairPredict India — Hack2Skill 2026

## What This App Does
An AI-powered **income classification system** built specifically for Indian socioeconomic realities.
It predicts whether a person earns **above or below ₹5 LPA** — with mathematical fairness constraints
that prevent bias against gender and caste categories.

## Why It's Different From the Original
| Feature | Original (US-based) | FairPredict India |
|---|---|---|
| Dataset | UCI Adult (American) | Indian synthetic dataset |
| Salary threshold | $50K USD | ₹5 LPA (Indian benchmark) |
| Education labels | US grade system | 10th / 12th / Graduate / PG |
| Prediction logic | **Hardcoded if/else** | **Real ML model** |
| Fairness | Loaded but unused | Actually enforced |
| Sensitive features | Gender, Race | Gender, Caste |

## How to Run Locally

### Step 1 — Install dependencies
```bash
pip install streamlit scikit-learn fairlearn pandas numpy joblib
```

### Step 2 — Train the model
```bash
python train_model.py
```
This creates `fair_india_model.pkl` in the same folder.

### Step 3 — Run the app
```bash
streamlit run app.py
```

## How to Deploy on Hugging Face

## Tech Stack
- **Streamlit** — UI framework
- **scikit-learn GradientBoostingClassifier** — core ML model
- **fairlearn ExponentiatedGradient + DemographicParity** — bias mitigation
- **pandas / numpy** — data processing

## Fairness Approach
The model uses **Demographic Parity** — a fairness constraint that ensures
the probability of a positive prediction (income > ₹5 LPA) is roughly equal
across gender groups, regardless of historical bias in training data.

Sensitive features (gender, caste) are **never used as prediction inputs** —
they are only used to enforce fairness constraints during training.

## Social Impact
India has significant income disparities across gender, caste, and region.
This tool demonstrates how AI can be designed to be part of the solution,
not part of the problem.
